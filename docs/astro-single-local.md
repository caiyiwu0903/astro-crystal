# 單題提問：本機試用交接

分支：`feature/cards-single-question-local`。未推送、未部署、未修改資料庫。首頁和其他服務頁未修改。

## 已完成

- 牌卡頁增加「三張牌指引／單題提問」，沿用網站樣式。
- 單題必填，最多 50 個字素（表情符號以完整字素計算）。
- 本機規則辨認 12 類問題，最多追問一次，3 個選項，可略過、修改問題。已具體或跨感情／職涯的模糊問題不硬套追問。關鍵字辨識不是 AI 理解，仍可能漏判。
- 後端從既有 36 張牌隨機抽一張，回傳理解問題、牌義角度、小行動與放心提醒。
- OpenAI Responses 介面：後端金鑰、結構化輸出、store:false、逾時、不自動付費重試、錯誤提示，不將服務失敗偽裝成 AI 回覆。
- 示範和 AI 模式明確區分。示範是規則文案，只供流程與版面確認。
- 不持久化問題、選項或解讀；不寫入網址、瀏覽器儲存或問答資料庫；伺服器不列印問答。
- 正式 AI 呼叫前要求同意資料送交 OpenAI。本網站不儲存不等於服務商零保留；store:false 也不代表零保留。
- 本機預覽注入停用統計旗標，原三張牌和單題試抽都不碰正式統計。

## 本機預覽

需 Node.js 22 或以上，不需安裝 npm 套件：

```powershell
node scripts/preview-astro-single.mjs
```

開啟 http://127.0.0.1:4174/astro-cards.html#single 。伺服器只綁定本機，不提供他人遠端使用。預設不讀取金鑰進行付費呼叫。

真正 AI 模式需在伺服器環境安全設定 `OPENAI_API_KEY` 與 `OPENAI_MODEL`，再使用 `--ai`。請勿將金鑰寫入前端、提交版本庫或分享。這次未設定金鑰，未進行真實 API 呼叫。

## 檢查

```powershell
node tests/astro-cards-engine.cjs
node tests/astro-single.mjs
# 已有 Playwright 的環境，搭配上述本機伺服器
node tests/astro-single-browser.cjs
# CARDS_TEST_WEBKIT=1 時使用 WebKit
```

後端測試涵蓋資料、追問規則、驗證、同意、模擬 OpenAI 請求／失敗和限流。瀏覽器涵蓋 375/390/430 寬度、選項／略過／修改／再問、50 字、原牌組網址、無正式統計請求與 JS 錯誤。桌面引擎手機尺寸測試不等同實機 iPhone／Android。
